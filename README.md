# tymewear

### Study repository for Tymewear validation manuscript

This repository reproduces the R code and `{targets}` pipeline with processing, analysis, plotting, and results for publication of the working title manuscript *"Tymewear validation manuscript"* 2026 by Bell J, Colgate N, Greco G, Arnold JI, Koehle MS.

The code is intact from the working project, however raw data are not included in this repository due to privacy restrictions, and therefore the code pipeline will not run as-is.

`bxb_data.rds` contains processed breath-by-breath data (`smooth = "width = 1"`). `binned_data.rds` contains 10-second binned averages (`smooth = "bin = 10"`) used for analysis.

Please contact the corresponding author Jem I Arnold (jem@jemarnold.ca) for more information.
